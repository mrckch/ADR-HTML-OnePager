Was berechnet diese Funktion?

def verdoppeln(zahl):
    return zahl * 2

# Tests:
print(verdoppeln(5))

Schreiben — jetzt du

3

Schreibe eine Funktion quadrat(zahl)

Die Funktion soll die Quadratzahl zurückgeben. Also: quadrat(5) → 25.

↗ Testen

Eine mögliche Lösung:

def quadrat(zahl):
    return zahl * zahl

Andere Wege sind möglich: zahl ** 2 oder pow(zahl, 2).

4

Schreibe eine Funktion ist_gerade(n)

Die Funktion soll True zurückgeben, wenn n gerade ist, sonst False. Tipp: Modulo-Operator %.

↗ Testen 
def ist_gerade(n):
    return n % 2 == 0

n % 2 gibt den Rest beim Teilen durch 2. Ist der Rest 0, ist die Zahl gerade.

★ 5

Bonus: Funktion maximum(a, b, c)

Die Funktion soll die größte der drei Zahlen zurückgeben — ohne max() zu benutzen.

↗ Testen 
def maximum(a, b, c):
    if a >= b and a >= c:
        return a
    elif b >= c:
        return b
    else:
        return c

Eleganter geht's auch:

def maximum(a, b, c):
    m = a
    if b > m: m = b
    if c > m: m = c
    return m
