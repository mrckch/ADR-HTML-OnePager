# Memory (Zuordnen)

16 Karten (bei 8 Paaren) verdeckt. Zwei aufdecken; passen sie, bleiben sie offen. Zählt die Züge.

- **Passt für:** Begriff und Erklärung, zwei Darstellungen derselben Sache, Vokabeln.
- **Jahrgang:** 5–10. **Dauer:** 3–5 Minuten. **Sozialform:** allein oder zu zweit abwechselnd.
- **Daten:** `TITEL`, `UNTERTITEL`, `PAARE` (Liste von zwei Texten). Keine AUFGABEN.
- **Gut zu wissen:** 6–8 Paare passen aufs Handy. Karten sind klein: Erklärungen kurz halten (bis etwa
  40 Zeichen). Jeder Text nur einmal, sonst ist das Paar nicht eindeutig.
- **Grenzen:** Merkfähigkeit spielt mit; für reines Wissen eher Zeit-Challenge.
