# Fachtag „Lernspiele mit KI“ (November 2026)

Was Teilnehmende in zwei Workshop-Runden gebaut haben, nur beschrieben (kein fremder Code, keine Namen).
34 Spiele, alle Mathematik.

| Thema | Spielformen |
|---|---|
| Brüche (5/6) | 2 Escape-Rooms, Tresor, Ziel treffen, Übungsspiel |
| Geometrie | Dreiecke abschätzen, Winkel, Flächen, Pythagoras als 60-Sekunden-Duell und als Escape-Room |
| Terme und Gleichungen (7/8) | Level-Spiel, Term-Werkstatt, Term-Abenteuer, Memory |
| Funktionen (9/10) | Funktions-Memory, Parabel-Golf (Parameter einstellen), Parabel-Flug |
| Koordinatensystem | Escape-Room, Western-Zielscheibe |
| Kopfrechnen | Schießspiel, Kopfrechnen 7/8 |
| Oberstufe | Escape-Room Integrale |
| Prozent | Escape-Room |

Erkenntnisse:
- Escape-Room war die häufigste Form (6), dann Zielen/Treffen (etwa 6), Level (3), Memory (2).
- Eine eigene Welt (Western, Golf) motiviert. Bei Welten aus Spielen für Erwachsene: weglassen.
- Häufigste Fehler beim Ablegen: leere Karten, kein Titel, Code als Text statt Datei, Dateinamen wie `spiel.html`.
- Ein Spiel lag auf einer öffentlichen Seite eines KI-Anbieters statt als Datei; besser HTML-Share.
- Daraus geplant im Katalog: `simulation` (Parabel-Golf), `schaetzen` (Dreiecke abschätzen).
